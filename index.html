🐙 Подключение через GitHub Pages (Открытие по ссылке с iPhone)

Чтобы открывать 3D-стенд на iPhone в Safari по обычной ссылке (и добавить иконку на экран «Домой» как приложение), разместите проект на бесплатном хостинге GitHub Pages:

Способ 1 — За 1 минуту прямо с телефона или ПК (без консоли):
  1. Нажмите кнопку ниже, чтобы скачать готовый главный файл index.html (или распакуйте архив репозитория).
  2. Зайдите на github.com/nemec8912-eng/toyota-engine-lab (прямая ссылка на загрузку файла | настройки Pages).
  3. Нажмите «uploading an existing file» (Загрузить существующий файл), выберите скачанный index.html и нажмите Commit changes.
  4. Перейдите в Settings → Pages, в разделе Branch выберите main / /(root) и нажмите Save (либо используйте автодеплой GitHub Actions из архива).
  5. Через 30–60 секунд откройте на iPhone ссылку https://nemec8912-eng.github.io/toyota-engine-lab/!
Способ 2 — Через Git в терминале (из готового архива репозитория):
git init
git add .
git commit -m "Deploy Toyota Engine Lab 1ZR-FE"
git branch -M main
git remote add origin https://github.com/nemec8912-eng/toyota-engine-lab.git
git push -u origin main
