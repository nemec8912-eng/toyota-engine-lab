# TOYOTA ENGINE LAB — 3D Диагностический стенд Toyota Corolla E150 (1ZR-FE 1.6L Dual VVT-i)

- **Репозиторий**: https://github.com/nemec8912-eng/toyota-engine-lab
- **Прямая ссылка для открытия на iPhone (GitHub Pages)**: https://nemec8912-eng.github.io/toyota-engine-lab/

## Быстрая публикация в ваш репозиторий `nemec8912-eng/toyota-engine-lab`

### Вариант А — Через браузер (с iPhone или ПК за 30 секунд)
1. Скачайте файл `index.html` (из этого архива или кнопкой **«📥 Скачать index.html»** внутри симулятора).
2. Откройте страницу загрузки вашего репозитория: https://github.com/nemec8912-eng/toyota-engine-lab/upload
3. Выберите `index.html` и нажмите зелёную кнопку **Commit changes**.
4. Откройте настройки GitHub Pages: https://github.com/nemec8912-eng/toyota-engine-lab/settings/pages
5. В разделе **Branch** выберите `main` (папка `/ (root)`) и нажмите **Save**.
6. Через 30–60 секунд стенд откроется на iPhone по ссылке: https://nemec8912-eng.github.io/toyota-engine-lab/

### Вариант Б — Через Git в терминале
```bash
git init
git add .
git commit -m "Deploy Toyota Engine Lab 1ZR-FE"
git branch -M main
git remote add origin https://github.com/nemec8912-eng/toyota-engine-lab.git
git push -u origin main
```
