# Toyota Engine Lab — 1ZR-FE

Виртуальный 3D-стенд и помощник по ремонту двигателя **1ZR-FE 1.6 Dual VVT-i** (Toyota Corolla E150).

**Открыть:** https://nemec8912-eng.github.io/toyota-engine-lab/
На iPhone: открыть в Safari → «Поделиться» → «На экран „Домой“» — работает как приложение, в том числе без интернета после первого открытия.

## Что умеет (пакеты 1–2)

- **3D-моторный отсек** E150 и двигатель со всем навесным: генератор, стартер, компрессор, помпа, ремень с натяжителем, впуск и дроссель, ДМРВ, катушки и свечи, форсунки, датчики, выпуск с катализатором, радиатор и вентилятор, АКБ, блок реле, ЭБУ.
- **Анимация двигателя**: коленвал, поршни и шатуны, распредвалы с муфтами VVT-i, клапаны, цепь ГРМ, ремень и шкивы, вентилятор, вспышки сгорания и искра по порядку работы 1-3-4-2. Замедление анимации до 1/25.
- **Режимы просмотра**: рентген, разрез по цилиндрам, изоляция детали, виды спереди/сверху/сбоку.
- **Разборка и сборка** с правильной последовательностью: что мешает снять, что нужно поставить раньше; болты откручиваются; крепёж, размер головки и момент затяжки для каждой детали. Снятые детали лежат на «верстаке» — их можно ставить на другие места (перестановка катушек и реле для диагностики).
- **Анимированная приборная панель** в стиле Optitron E150: тахометр с ЖК-шкалами топлива и температуры, спидометр 0–240 с дисплеем, прогон стрелок и проверка ламп при включении зажигания, Check Engine (мигает при пропусках), лампы зарядки и давления масла, просадка подсветки при прокрутке.
- **Ключ зажигания** LOCK/ACC/ON/START и педаль газа. Прогрев, вентилятор, зарядка, перегрев без ремня помпы.
- **Электрика**: питание по цепочке АКБ → предохранители (AM2, EFI MAIN, EFI NO.2, IG2, ETCS, ALT-S, RDI) → реле (EFI, C/OPN, ST, FAN) → ЭБУ и исполнительные цепи.
- **Мультиметр** (V⎓, V~, Ω, прозвонка) и **контрольная лампа**: щупы ставятся касанием на точки в 3D — выводы разъёмов, клеммы АКБ, площадки предохранителей, выводы реле и гнёзда.
- **OBD-II сканер**: коды ошибок со стоп-кадром, стирание, живые параметры (обороты, ОЖ, ДМРВ, коррекции STFT/LTFT, O2, VVT цель/факт, пропуски по цилиндрам…).
- **10 сценариев неисправностей** с пошаговыми подсказками и **экзамен** со случайной скрытой неисправностью и оценкой (время, лишние замены).

## Важно

Моменты затяжки, нормы, распиновка и расположение некоторых узлов (ЭБУ, блок реле, датчики) — **ориентировочные**. Схемы электрики упрощены. Перед реальным ремонтом сверяйтесь с заводским руководством (RM/EWD) для своего VIN.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run typecheck
```

Стек: TypeScript, Three.js, esbuild. Публикация — GitHub Actions → GitHub Pages при пуше в `main`.

- `src/data/parts.json` — база деталей: описание, порядок разборки (`blockedBy`), крепёж, нормы.
- `src/data/faults.json` — сценарии неисправностей: дефекты, жалоба, подсказки. Новые сценарии добавляются комбинацией готовых дефектов без правки кода.
- `src/sim/engine.ts` — симуляция двигателя, электрики и ЭБУ (коды ошибок).
- `src/sim/probes.ts` — точки замера и расчёт показаний приборов.
- `src/scene/model.ts` — процедурная 3D-модель (позже заменяется детальными glTF-моделями).
- `src/ui/cluster.ts` — приборная панель.

Предыдущая версия (ChatGPT/Gemini) сохранена в ветке `old`.
